## Problem: Valid Anagram (Easy)

**Link:** Valid Anagram — LeetCode

### Approach

Use a frequency array to count the characters in both strings. Increase the count for each character in the first string and decrease it for the corresponding character in the second string.

### Complexity

* Time: O(n)
* Space: O(1)

### Notes

Tested locally with two test cases: one typical case and one edge case. The solution was then submitted on LeetCode.
